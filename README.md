# Енергія дому

Android-додаток для настінного планшета: моніторинг гібридного інвертора Deye (SUN-*-SG0xLP1) і JK BMS **без сервера**.

- Інвертор — напряму з Wi-Fi логера Solarman (протокол V5, TCP 8899), **лише читання** (Modbus 0x03).
- АКБ — JK BMS по Bluetooth LE, лише запити стану.
- Локальна історія (SQLite) для графіків дня й тижня.
- Android 7.0+ (minSdk 24), без Google Play Services. Демо-режим для перевірки без обладнання.
- Автозапуск після ввімкнення, екран не гасне.

## Налаштування
⚙ у правому верхньому куті (або довге натискання на «Енергія»): IP і серійний номер логера, ємність АКБ, вибір BMS.

## Оновлення
Додаток раз на ~6 год (і при запуску) завантажує `version.json` з останнього релізу (`releases/latest/download/`), потім `energiya-domu.apk`, звіряє SHA-256 і сертифікат підпису.
Тихе встановлення працює, якщо додаток — власник пристрою (на планшеті без облікових записів Google):

```
adb shell dpm set-device-owner ua.sister.energy/.AdminReceiver
```

Інакше Android покаже звичайний запит на встановлення.

Регістри Deye — за [ha-solarman](https://github.com/davidrapan/ha-solarman) (`deye_hybrid.yaml`); протокол JK BMS — за [esphome-jk-bms](https://github.com/syssi/esphome-jk-bms).

## Сповіщення на телефон
Планшет надсилає події (зникло/з'явилось світло, низький заряд АКБ, аварія інвертора, немає зв'язку з BMS або логером) у випадкову тему на [ntfy.sh](https://ntfy.sh).
Модуль `notify/` — окремий застосунок для телефона «Енергія — сповіщення» (`ua.sister.energy.notify`): прив'язка скануванням QR з налаштувань планшета або введенням коду, великі шрифти, підказки для Xiaomi/HyperOS.
Реліз містить `energiya-notify.apk` і `version-notify.json`; телефон перевіряє оновлення і пропонує встановити.

Android 7 не довіряє сертифікатам Let's Encrypt (ntfy.sh) — тому в застосунки вбудовано кореневі сертифікати ISRG Root X1/X2 (`res/raw`, `network_security_config.xml`).

## Віддалений моніторинг BMS (з 1.5.5)
Планшет надсилає компактний стан JK BMS у хмарний MQTT (EMQX Cloud Serverless) під вшитим логіном **Hmarskie**
(логін змінити не можна): раз на 60 с, кожні 5 с коли хтось дивиться цей логін на сторінці
[BMS Remote](https://oselia.tail5a289e.ts.net/bms-remote/), події внутрішнього опору — одразу.
Формат топіків і payload — як у додатку BMS LCD 0.3.1. Демо-дані не надсилаються.
Облікові дані брокера вшиваються під час збірки з файлу секретів або змінних середовища, не з git.
