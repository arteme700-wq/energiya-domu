# Енергія дому

Android-додаток для настінного планшета: моніторинг гібридного інвертора Deye (SUN-*-SG0xLP1) і JK BMS **без сервера**.

- Інвертор — напряму з Wi-Fi логера Solarman (протокол V5, TCP 8899), **лише читання** (Modbus 0x03).
- АКБ — JK BMS по Bluetooth LE, лише запити стану.
- Локальна історія (SQLite) для графіків дня й тижня.
- Android 7.0+ (minSdk 24), без Google Play Services. Демо-режим для перевірки без обладнання.
- Автозапуск після ввімкнення, екран не гасне.

## Налаштування
⚙ у правому верхньому куті (або довге натискання на «Енергія»): IP і серійний номер логера, ємність АКБ, вибір BMS.

## Оновлення
Додаток раз на ~6 год перевіряє останній реліз цього репозиторію (`version.json` + APK), звіряє SHA-256 і сертифікат підпису.
Тихе встановлення працює, якщо додаток — власник пристрою (на планшеті без облікових записів Google):

```
adb shell dpm set-device-owner ua.sister.energy/.AdminReceiver
```

Інакше Android покаже звичайний запит на встановлення.

Регістри Deye — за [ha-solarman](https://github.com/davidrapan/ha-solarman) (`deye_hybrid.yaml`); протокол JK BMS — за [esphome-jk-bms](https://github.com/syssi/esphome-jk-bms).
